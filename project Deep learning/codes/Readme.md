

# Deep Learning Web Application

This project demonstrates how to integrate a **Deep Learning model** with a **web application** using a clear separation between:
- Model training
- Backend API
- Frontend interface

The system allows users to input data through a web page and receive predictions generated by a trained deep learning model.

---

## 📂 Project Structure
project Deep learning/
 │
 ├── model.ipynb 
 ├── app.py 
 └── project deep learning.php


---

##  File Descriptions

### 1 model.ipynb — Model Development
This notebook is responsible for:
- Loading and preprocessing the dataset
- Building the Deep Learning model
- Training and evaluating the model
- Saving the trained model for later use in deployment

⚠️⭕️ This file is used only during development and training, not during runtime.

---

### 2 app.py — Backend & Model Integration
This file acts as the backend server and includes:
- Loading the saved Deep Learning model
- Running a Flask API server
- Receiving input data from the frontend
- Performing inference using the trained model
- Returning predictions to the frontend

The backend serves as a bridge between the web interface and the model.

---

### 3 project deep learning.php — Frontend Interface
This file represents the user interface of the application and includes:
- Input forms for user data
- Sending requests to the Flask backend
- Displaying prediction results to the user

The frontend communicates with the backend using HTTP requests.

---

##  System Workflow

1. The user enters input data on the web page.
2. The PHP frontend sends the data to the Flask backend.
3. The backend loads the trained model and processes the input.
4. The model generates a prediction.
5. The backend sends the result back to the frontend.
6. The prediction is displayed to the user.

User → PHP Page → Flask API → Deep Learning Model → Result

---

##  How to Run the Project

### 1️⃣ Train the Model
Open and run the notebook:
model.ipynb
Make sure the trained model is saved (e.g., model.h5).

---

### 2️⃣ Start the Backend Server
Install dependencies:
pip install flask tensorflow numpy


Run the backend: app.py

The Flask server will start on: local host

---

### 3️⃣ Run the Frontend
- Place project deep learning.php in your PHP server directory (e.g., htdocs for XAMPP).
- Start Apache server.
- Open the page in your browser.
